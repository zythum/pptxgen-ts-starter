# Workflow 07 — QA: Checks & Second-Pass Review

**Goal:** verify the deck before delivery, fix issues with the right lever
(shorten text vs enlarge box; fine-tune layout vs switch layout rule), then
re-check everything a second time.

## Severity levels (borrowed from guizang-ppt-skill)

| Level  | Meaning                              | Action                    |
| ------ | ------------------------------------ | ------------------------- |
| **P0** | Broken — would embarrass on stage    | Must fix now, never defer |
| **P1** | Wrong but visible only on close look | Fix before delivery       |
| **P2** | Suboptimal aesthetics                | Fix if cheap; note if not |
| **P3** | Taste / optional                     | Leave; don't churn        |

## Checklist

### P0 — Geometry & correctness

- [ ] Every element has `x`, `y`, `w`, `h` in inches; nothing overflows canvas
      (x+w ≤ 13.333, y+h ≤ 7.5)
- [ ] No overlapping text blocks (measure with `estimate-text.ts`, sum y+h)
- [ ] Text fits its container `h` — measured, not guessed
- [ ] Images use native aspect ratio in container (checked with `image-tool.ts`)
- [ ] No placeholder text (Lorem, TODO, XXX, undefined) — grep before delivery
- [ ] No fabricated data/numbers; every stat has a source in the outline
- [ ] Slide files import correctly and `src/ppt.tsx` includes all slides

### P1 — Typography & alignment

- [ ] ≤ 2 font families; title ≈ 2× body; body ≥ 14 pt
- [ ] Body left-aligned; center only hero/quote text
- [ ] `fontFace` / `fontSize` come from `src/token/typography.ts`
      (`typography.*`) — grep for magic numbers; per-slide exceptions carry a
      comment
- [ ] `breakLine: true` on last `TextRun` of each line
- [ ] No justified mixed CJK/Latin text
- [ ] One bold takeaway phrase per slide max
- [ ] Cards in a row: identical geometry + equal gaps; related blocks align
- [ ] Same margins (0.8 in) everywhere; same title position across pages

### P1 — Color

- [ ] All colors come from `src/token/colors.ts` (`colors.*`) — grep for bare
      hex in `src/slides/` and fix any that slipped in
- [ ] Hex without `#` (inside `colors.ts`)
- [ ] One accent; accent coverage ≤ ~10%
- [ ] Body contrast ≥ 4.5:1 (muted ≥ 3:1); no pure black/white for large areas
- [ ] Semantic colors only where meaningful

### P1 — Content & density

- [ ] ≤ ~50 words per slide; one idea per slide
- [ ] Density alternates; ≥ 1 sparse slide per ~6 slides
- [ ] Cover and closing echo each other; sections follow the chosen narrative
- [ ] `.deck/` files (brief/research/outline/spec) match the final deck;
      slide-top comments reflect the actual content (update them when editing)

## Fix with the right lever

| Problem                   | First try                                  | Then try                            |
| ------------------------- | ------------------------------------------ | ----------------------------------- |
| Text overflows box        | **Shorten text** (cut filler, split slide) | Enlarge box / reduce font size      |
| Image stretched           | **Re-crop/re-size asset** to slot ratio    | Change slot to asset ratio          |
| Elements overlap          | **Fine-tune coordinates** (shift, gap)     | Switch to a different locked layout |
| Page feels crowded        | Reduce content (one idea rule)             | Split into 2 pages                  |
| Layout looks inconsistent | Re-check against layout template           | Switch both pages to same template  |

## Verification commands

```
npx tsx scripts/estimate-text.ts -w 5.7 -f "16pt Inter" --leading 24 "text…"
npx tsx scripts/image-tool.ts --image src/media/images/photo.png
npx tsx scripts/color-tool.ts --hex 1F2937 --hex F9FAFB --contrast
rg -n '"[0-9A-Fa-f]{6}"' src/slides/ src/components/  # bare hex in slides = defect
rg -n "fontSize: [0-9]|fontSize=\{[0-9]|fontFace: \"" src/slides/ src/components/  # magic type numbers = defect
npm run typecheck
npm run lint
npm run generate
```

Then open `output/presentation.pptx` in the browser viewer (dev server) and
**look at every slide** — visual review catches what scripts can't.

## Second-pass review

After fixing, run the full checklist **again** from scratch:

1. Re-measure any text that changed.
2. Re-check images that were swapped.
3. Grep for leftover placeholders: `rg "TODO|Lorem|XXX" src/`
4. Flip through the deck in order and check **page-to-page alignment**
   (titles at same y, margins consistent, rhythm alternating).
5. Read speaker notes aloud mentally — do the transitions flow? Does the
   presenter know when to pause/interact?
6. Final gate: if anything is P0 or P1, it is not delivered.

## QA mindset

- The reviewer is a skeptic in the back row who cannot read small text.
- If you can't justify an element's presence, remove it.
- Design is done when there is nothing left to remove, not when nothing more
  can be added.
